### Features
With this tool, you can manage your system faster without typing complex commands:
* **Package Management:** Install or remove programs via apt.
* **Disk Tools:** Format partitions or disks easily.
* **Flashing:** Flash your phone using Heimdall.
* **Compatibility:** Run Windows programs via Wine.
* **File Editing:** Edit or create text files quickly via nano.
* **File Removal:** Permanently remove files via rm.
* **File Creation:** Create new folders instantly.

> **Note:** Changing directories via cd is currently broken and will be removed in the next update.

### Installation Steps

1. Purchase and download the `simplified-terminal` binary file from our store link above.
2. Open your Linux terminal.
3. Navigate to the folder where the downloaded file is located.
4. Move the binary to your local system path by running:
```bash
sudo cp simplified-terminal /usr/local/bin/
```
5. Give execution permission to the file:
```bash
sudo chmod +x /usr/local/bin/simplified-terminal
```
